# 尔玉分享视觉规则

## 视觉优先级

### A / Paper & Ink

默认用于封面、观点、问题、案例叙事、章节过渡和结尾。

- 背景：纸张色、白色或极浅灰。
- 文字：炭黑为主，冷绿只做结构强调。
- 版式：编辑部层级、细分隔线、不对称留白、少量元数据。
- 动效：淡入、短距离进入、局部高亮，不做大幅飞入。

### C / Eryu Custom

只用于系统关系、真实工作流、任务状态、证据链和工具协作。

- 单页最多三个主要模块。
- 单页最多一条主流程。
- 七至十页演示中原则上最多两页。
- 工作台只是局部结构，不切换成高密度控制台。
- 便签和标签必须承载真实状态或证据。

## Token

```css
:root {
  --eryu-ink: #1d2023;
  --eryu-carbon: #2a2d30;
  --eryu-paper: #f4f1ea;
  --eryu-white: #fbfbf8;
  --eryu-mist: #dde1e0;
  --eryu-cold-green: #2f9f8d;
  --eryu-slate-blue: #9aaabd;
  --eryu-note-yellow: #e7d9a7;
  --eryu-soft-sage: #b7c4a9;
}
```

纸张色占页面视觉面积的 70% 至 85%，冷绿通常不超过 5%。一个页面只使用一个主强调色。

## 人物资产

- 主形象承担专业识别，不承担正文信息。
- Q 版承担解释和轻提示，不用于支付、合规、严重错误或正式数据页。
- 不自动裁切人物图生成 Logo。
- 不公开真实正脸、侧后方照片或未授权人物素材。

## 禁止项

- 默认紫蓝渐变、玻璃拟态、黑金、赛博霓虹。
- 无关系的等尺寸卡片墙。
- 装饰性便签、重复标签、无意义连线。
- 持续漂浮、旋转、粒子、呼吸光和强视差。
- 把未经确认的个人经历、数据和合作方做成视觉事实。
