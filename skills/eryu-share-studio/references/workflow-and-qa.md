# 分享生产与验收

## 内容计划

先创建 `content-plan.md`，至少包含：

- 分享目标、听众、时长和一句核心判断。
- 每页标题、主要判断、证据、视觉类型和预计讲述时间。
- 需要用户确认的事实、数字和公开边界。
- A / C 页面分配及人物资产位置。

常规七页结构可参考：

1. 封面与核心判断。
2. 问题或背景。
3. 系统关系或关键方法。
4. 真实案例。
5. 失败、限制或反例。
6. 可复用方法。
7. 结论、下一步或联系方式。

不要为了凑页数保留重复观点。需要更多内容时增加证据页或案例页，不增加空泛章节。

## 静态优先

1. 先关闭所有动画完成排版。
2. 检查最长标题、最长段落、图片缺失和字体 fallback。
3. 确认每页只有一个主阅读路径。
4. C 页面超过三个模块时拆页。
5. 静态版通过后再添加动效。

## 动效

- 内容进入：8 至 16px，150 至 320ms。
- 列表：短间隔 stagger，不逐字长时间播放。
- 流程：按讲述顺序点亮节点，不循环播放。
- 数据：可短时递增，但最终数字在无动画模式直接显示。
- PDF：动画全部进入最终状态。

## 浏览器验收

至少检查：

1. `1920x1080` 桌面截图。
2. `1440x900` 常规桌面截图。
3. `390x844` 移动端截图和翻页。
4. `prefers-reduced-motion: reduce`。
5. 浏览器控制台错误和警告。
6. 本地图片尺寸、加载状态和替代文本。
7. PDF 首尾页、空白页、裁切、背景和字体。

在 `verification.md` 写明实际结果，不只复制检查清单。
