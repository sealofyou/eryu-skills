# 尔玉分享工坊

## 定位

把内容整理、个人品牌注入、Frontend Slides 编排和浏览器验收收敛为一条分享生产线。默认交付可离线打开的单文件 HTML，并按需导出 PDF、演讲备注和截图。

不要用本 Skill 制作普通个人主页、产品控制台或长篇网页报告；这些任务交给 `eryu-dynamic-web-publisher` 路由。

## 读取上下文

1. 读取用户提供的主题、材料、受众、时长和交付要求。
2. 定位 `eryuOS`：优先读取环境变量 `ERYUOS_ROOT`，其次从当前目录向上查找，再参考机器路径规则；不要把 Windows 路径写成跨机器事实。
3. 找到 `eryuOS` 后按需读取：
   - `DESIGN.md`
   - `05_表达与品牌/个人IP视觉与生图规约.md`
   - `04_内容生产/AI玩尔玉视觉风格基底.md`
   - `05_表达与品牌/assets/ai-wan-eryu/dual-image-v1/README.md`
   - 与分享主题直接相关的个人事实、项目卡或知识文档
4. 只读取当前分享需要的模块，不全量加载个人资料。

不得把私有路径、凭据、未确认经历、客户敏感信息或内部推理标签放进对外交付物。

## 上游选择

优先读取独立安装的 `frontend-slides` Skill，并沿用其单 HTML、浏览器编辑、键盘翻页和 PDF 导出能力。不要复制或改名上游仓库；本 Skill 只负责尔玉的内容、视觉和验收覆盖。

如果 `frontend-slides` 未安装，提示通过 `eryu-skills` 的 `core` 配置安装；任务紧急时可以直接生成等价的单文件 HTML，但必须保留本 Skill 的输出和验收约束。

## 固定视觉策略

- 默认使用 **A / Paper & Ink**：纸张色、编辑部层级、清晰留白和克制冷绿。
- 只在系统关系、工作流、证据链或工具协作页使用 **C / Eryu Custom**。
- 七至十页的普通分享中，C 控制在一至两页；单页最多三个主要模块和一条主流程。
- 便签、标签、连线和状态块必须承载真实信息，不做装饰。
- 能用一句判断和一张图说清楚时，回到 A，不使用工作台布局。
- 主形象只用于封面、章节或结尾；Q 版只用于解释、避坑和轻提示。

详细规则见 `references/style-system.md`。

## 工作流

1. 锁定受众、时长、分享目标、核心判断和公开边界。
2. 生成 `content-plan.md`：每页只保留一个主要判断，并标记证据、素材和讲述时间。
3. 先完成无动画静态版，检查内容层级和信息密度。
4. 以 A 编排大多数页面，只把确有关系表达需求的页面切为 C。
5. 添加服务于理解的短距离进入、局部高亮和流程点亮；支持 `prefers-reduced-motion`。
6. 输出 HTML，并按需生成 PDF、`speaker-notes.md` 和截图。
7. 用浏览器完成桌面、移动端、无动画和控制台验收，再修复失败项。

具体页面结构和验收步骤见 `references/workflow-and-qa.md`。

## 输出

```text
output/
├── content-plan.md
├── speaker-notes.md       # 需要时
├── index.html
├── export.pdf             # 需要时
├── screenshots/
└── verification.md
```

只生成用户实际需要的文件，不机械产出所有格式。需要原生可编辑 PPTX 时，明确切换到 Dashi 或 PPT Master 专项路线；不要宣称 HTML 导出的图片页 PPTX 是原生可编辑对象。

## 完成 Gate

- 桌面 `1920x1080` 与 `1440x900` 无遮挡、溢出和孤字。
- 移动端 `390x844` 可翻页并正确缩放；固定舞台允许留白，但不能裁切。
- 禁用动画后内容完整，PDF 进入最终静态状态。
- 浏览器控制台无错误，图片与字体有 fallback，断网时核心内容可读。
- 没有紫蓝渐变、玻璃卡片墙、黑金、霓虹、持续粒子和无意义动效。
- `verification.md` 记录实际检查项、失败修复和未验证边界。
