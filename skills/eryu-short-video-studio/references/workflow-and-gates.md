# 通用流程与 Gate

## 流程总览

| 阶段 | 产物 | 完成标准 | 默认审核点 |
| --- | --- | --- | --- |
| 0. 项目建立 | `project-state.yaml` | 平台、时长、模式、主题清楚 | - |
| 1. 路线卡 | `review-board.md` | 观众、核心判断、形态、前 5 秒、素材清楚 | A |
| 2. 事实锁 | `fact-card.md` | 已完成/未完成/待确认分开，公开边界明确 | high-control |
| 3. 口播与分幕 | `speaker-notes.md` `content-plan.md` | 一条只讲一个判断，切幕与口播对应 | B |
| 4. 静态视觉 | 首屏/转折/结尾预览 | 不像竖版 PPT，个人 IP 承担动作 | B |
| 5. 音频 | WAV/MP3/SRT/时间戳/cue | 无缺句、串词、异常短句，可解码 | C 的一部分 |
| 6. 动态主轨 | HTML/Remotion | 1080×1920，禁用动画后仍完整，无错误 | high-control |
| 7. 成片 | MP4/联系表/封面 | 技术 Gate + 抖音安全区 Gate 通过 | C |
| 8. 发布包 | MP4/PNG/MD/TXT | 文件唯一，尺寸、时长、哈希已记录 | D |
| 9. 平台发布 | 平台状态 | 账号、话题、封面、范围回读正确 | D/已授权 |
| 10. 归档复盘 | 完整工程与复盘 | 可恢复、可复用、可找到 | - |

## 路线卡必填

```md
目标观众：
他们已经知道什么：
看完只需要记住什么：
视频类型：能力介绍 / 技术分析 / 真实实测 / 教程 / 复盘
核心判断：
前 5 秒：
主视觉动作：
时长：
需要的真实素材：
是否需要付费实测：
不进入这条的内容：
```

## 技术内容拆分规则

同一主题同时存在以下目标时，先拆再做：

- 能力介绍：让人看到原来可以这样做。
- 技术分析：说清原理、系统和边界。
- 真实实测：展示输入、参数、多次结果、耗时、费用和失败。
- 教程：让观众可以跟着做。

普通观众视频不得只用“它很难”建立价值。如果观众没有难度标尺，先换成他们已经遇到的问题或可直接看见的结果。

## 成片平台 Gate

- 首帧立即成立，不从近空白淡入开始。
- 顶部 150px 不放关键信息。
- 右侧保留约 130–150px。
- 字幕底部离底约 280–330px。
- 结尾保留约 0.8–1 秒阅读时间。
- 不存在页面文字与字幕同句重复。
- 封面单独制作并检查主页裁切。
- 不启用平台自动字幕制造双字幕。

## 发布状态

只使用：

1. `assets_ready`
2. `uploaded_not_submitted`
3. `submission_sent`
4. `review_or_indexing`
5. `visible_in_creator_list`
6. `publicly_visible_verified`

不得从页面跳转或成功 toast 推断公开可见。
