# 异常分支

| 编号 | 触发条件 | 立即动作 | 恢复条件 |
| --- | --- | --- | --- |
| F01 | 人物、顺序、数字或完成状态被纠正 | 停止口播与画面，回到事实卡 | 事实 lock 重新批准 |
| V01 | 9:16 画面仍像方块 PPT | 废弃卡片布局，改为全屏动态叙事 | 连续三幕手机预览通过 |
| V02 | AI 味重或个人 IP 只是角标 | 减少模板标签，让人物承担动作 | B 审核通过 |
| S01 | 存在多个相似音色任务 | 禁止生成，读取用户指定历史 | 唯一 Session/服务商/模型锁定 |
| M01 | 服务商或模型与用户选择不一致 | 立即停止 API 与计费 | 从事实源确认参数 |
| A01 | TTS 缺句、异常短句或串入参考文本 | 停止渲染，逐句 ASR 与时长检查 | 音频 Gate 通过 |
| R01 | FFmpeg 缺字幕滤镜 | 使用 HTML/Remotion 原生字幕 | 冒烟样片可解码 |
| U01 | Browser 结构化控制连续超时 | 保留同一登录态，依规则换可见交互方式 | 设置可回读 |
| D01 | 话题自动匹配错误或富文本被拆坏 | 恢复纯简介，话题逐个添加与回读 | 文案与发布卡一致 |
| O01 | 验证码、CAPTCHA、扫码或账号选择 | 请求用户接管或瞬时提供，不持久化 | 验证通过 |
| P01 | 页面跳转但作品未出现 | 记录 `submission_sent` 或 `review_or_indexing`，不重复发 | 列表或公开页可见 |

同一故障不重复猜测修复。先把可恢复状态写回 `project-state.yaml`，再切换路径。
