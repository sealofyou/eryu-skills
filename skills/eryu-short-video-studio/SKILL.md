# 尔玉短视频工坊

## 定位

把一条短视频当作可恢复的小项目，不当作一次性生成。全程维护 `project-state.yaml`，让用户随时看到当前阶段、已完成产物、待确认问题和下一步。

默认交付：

> 事实卡 + 内容路线 + 口播 + 9:16 视觉主轨 + 本人音色 + 原生字幕 + 成片 + 独立封面 + 发布文案 + 验收与发布状态。

## 选择执行模式

根据用户请求选择：

- `plan`：只做调研、内容路线、口播结构和视觉方案，不调用付费 API，不生成成片。
- `produce`：生成音频、HTML、字幕、成片、封面和发布包，不上传平台。用户只说“做一条视频”时默认此模式。
- `publish`：已有成片，只做平台上传、封面、文案、验证码与状态确认。
- `full`：从素材走到发布。只有用户明确要求全流程或直接发布时才进入。

付费 API、充值、购买会员和最终发布不因 `full` 自动获得权限；必须由用户当前请求明确授权。

## 初始化项目

新视频优先运行：

```bash
python3 scripts/init_project.py \
  --output <目录> \
  --title "<标题>" \
  --slug <ascii-slug> \
  --mode produce \
  --platform douyin \
  --review-mode standard
```

该脚本复制 `assets/project-template/`，生成可供未来前端直接读取的项目状态文件。现有项目不强制重建，但要补齐 `project-state.yaml` 与 `review-board.md`。

## 四个用户审核点

默认使用 `standard` 审核模式，只在以下节点停下等用户：

### A. 路线卡

展示：目标观众、核心判断、视频形态、时长、前 5 秒、主视觉、需要的真实素材、是否需要付费实测。

用户在这里决定“到底要做成什么样”。未通过不写完整口播。

### B. 口播 + 静态视觉

同时展示：完整口播、分幕表、首屏、转折幕、结尾幕静态预览。口播和画面必须是同一版本。

用户在这里审文案、信息密度、AI 味、个人 IP 和基本审美。未通过不生成正式音频。

### C. 音色 + 成片联系表

展示：音色候选或已锁定音色、句级时间戳、成片联系表、独立封面和直发验收结论。

用户在这里选音色、看节奏、看字幕安全区和封面。未通过不上传平台。

### D. 发布卡

展示：最终文件、账号、标题、简介、话题、封面、公开范围、允许保存、自动字幕、同步设置和预计费用。

用户已在当前请求明确授权“直接发布”时，不重复询问；登录、验证码、CAPTCHA、账号不明或设置与发布卡不一致时仍然停止。

## 快速与高控制模式

- `fast`：只保留 A、C、D；适用于已经有稳定风格和明确素材的高频内容。
- `standard`：保留 A、B、C、D；默认。
- `high-control`：在 B 之前额外审核事实卡，在 C 之前额外审核完整无动画 HTML；适用于敏感经历、新视觉方向或高成本生成。

用户没有指定时使用 `standard`。不得为了“效率”自动降级审核模式。

## 生产规则

1. 真实经历先建立“已完成 / 未完成 / 待确认”事实锁。
2. 技术模型内容先区分能力介绍、技术分析、效果实测和操作教程；默认不挤在同一条。
3. 口播使用具体动作和真实判断，不用泛化知识博主腔；需要时调用 `shuorenhua`。
4. 9:16 画面必须是全屏动态叙事，不是竖版 PPT、卡片墙或横屏页面拉长。
5. Q 版人物或个人 IP 必须承担观察、操作、反应或引导，不只当角标。
6. 先完成无动画静态版，再加服务于理解的进入、移动和点亮。
7. 音色、服务商、模型、正文和版本从事实源读取，不凭任务名或聊天记忆猜。
8. 成片必须过技术 Gate 和平台观看 Gate；文件存在不算完成。
9. 上传、已提交、审核中、作品列表可见和公开可见必须分开记录。
10. 每一阶段完成后更新 `project-state.yaml` 和 `review-board.md`，再进入下一步。

## 状态回报

每次更新只报四项：

```text
已完成：
当前阶段：
需要你确认：
确认后我会：
```

没有用户决策也能继续的工作应继续完成，不把所有小问题都抛回用户。

## 完成 Gate

- 用户能通过 `review-board.md` 知道视频将做成什么样。
- `project-state.yaml` 与实际文件、版本和平台状态一致。
- 事实、口播、HTML、音频、SRT、cue、成片和发布文案使用同一版本。
- 用户的个人 IP、声音和审美选择能在成片中看到，不是通用 AI 模板。
- 成片、独立封面、发布文案和完整工程已按要求交付与归档。
- 若执行发布，最终回复明确停在哪一个平台状态，不夸大。
