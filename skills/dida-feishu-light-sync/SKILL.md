# 滴答飞书轻量巡检

## 目标

保持滴答到飞书的同步正确性，同时减少读取范围、重复快照和无变化落盘。

## 读取入口

1. 通过 `ERYUOS_ROOT`、当前目录向上查找或机器路径规则定位 `eryuOS`。
2. 读取 `08_任务与节奏/README.md`、自动化运行规则和任务同步提示词。
3. 只读取完成差异判断所需的状态文件，不加载历史运行日志全文。
4. 当前机器没有滴答或飞书授权时，报告缺失入口，不猜测另一台机器的路径和凭据。

## 固定规则

- 飞书只投影任务名、状态、截止时间、提醒时间、滴答任务 ID、备注和完成时间等必要字段。
- 滴答优先读取未完成任务；做日期比较前统一换算到 `Asia/Shanghai`。
- 优先使用当前会话已有的滴答和飞书能力；连接失败后再读取 `eryuOS` 记录的本机回退入口。
- 无变化时只更新最近巡检摘要，不追加长篇 ledger 和原始快照。
- 有变化时只记录变化项；失败只有影响正确性或需要后续处理时才进入长期记录。

详细差异和落盘约束见 `references/sync-contract.md`。

## 禁止

- 不为无变化巡检生成整轮任务清单。
- 不把飞书或滴答原始快照写入 Git。
- 不把 token、secret、cookie、账号密码或 Base 私有数据写入 Skill 仓库。
- 不因单一接口暂时失败就重复调用所有连接器。
- 不修改巡检频率，除非用户明确要求。
