# 输出路由边界

## 使用 `eryu-share-studio`

- 分享、演讲、课程、项目复盘。
- 横向翻页 HTML。
- 同一套内容需要 HTML 与 PDF。
- 用户提到 PPT，但接受浏览器演示或图片页备份。

## 使用 report

- 阅读顺序是从上到下而不是逐页讲述。
- 需要正式分页、页码、页眉页脚或脚注。
- PDF 是主要归档物，动效只是屏幕增强。

## 使用 site

- 需要响应式网页、个人主页或产品页原型。
- 页面存在导航、表单、长滚动或产品状态。
- 目标是验证设计和信息架构，不是生成完整业务系统。

## 不属于本 Skill

- 原生可编辑 PowerPoint 对象。
- 正式业务后台、登录、支付、计费和 API Key 管理。
- 视频渲染和 MP4 交付。
- 大型三维场景和游戏。
