# 尔玉动态网页发布

## 定位

作为尔玉网页类交付的轻量路由层，统一读取 `DESIGN.md` 和个人 IP 规则，但不复制上游框架和大型模板。

## 选择模式

| 目标 | 模式 | 默认路线 |
| --- | --- | --- |
| 分享、演讲、课程、项目复盘、HTML PPT | `deck` | **必须使用 `eryu-share-studio`** |
| 长文方案、案例、白皮书、网页与 PDF 双交付 | `report` | 语义 HTML + Print CSS；按需 Paged.js |
| 个人主页、中转站、产品页视觉验证 | `site` | 响应式 HTML 原型；确认后迁入正式项目 |

代码课程、Vue 组件和复杂现场交互可专项使用 Slidev。强舞台、WebGL 或杂志化章节可专项参考 Guizang。需要原生可编辑 PPTX 时切换 Dashi 或 PPT Master，不由本 Skill 假装完成。

## 读取规则

1. 先读当前内容源和交付要求。
2. 通过 `ERYUOS_ROOT`、当前目录向上查找或机器路径规则定位 `eryuOS`。
3. 按需读取 `DESIGN.md`、个人 IP 视觉规约、视觉风格基底和当前任务对应模块。
4. 只加载当前模式需要的资料，不全量读取 `eryuOS`。
5. 不公开私有事实、真实凭据、内部路径和未确认信息。

## 通用覆盖

- 背景以纸张色、白色和浅灰为主，炭黑负责结构，冷绿负责有限强调。
- 不默认使用紫蓝渐变、玻璃拟态、黑金、霓虹、粒子和营销型空泛 Hero。
- 卡片必须承载关系、状态或动作；不生成等尺寸卡片墙。
- 动效只用于解释流程、状态、数据和阅读顺序，并支持 reduced motion。
- 正式个人主页、控制台和长期产品前端进入独立项目，不长期停留在原型目录。

## 模式工作流

### deck

直接切换到 `eryu-share-studio`，沿用其 A 主风格、C 辅助页、内容计划、Frontend Slides 和浏览器验收规则。本 Skill 不再把 Guizang 设为普通分享默认上游。

### report

- 使用语义化结构和独立 `@media print`。
- 设置稳定纸张尺寸、页边距、页眉页脚、分页和孤行控制。
- 图表、表格、代码和证据块避免跨页截断。
- 屏幕动效在打印时进入最终静态状态。
- Paged.js 不可用时退回 Chromium 打印 CSS，不阻塞交付。

### site

- 首屏直接展示真实人物、产品或工作状态，不做空泛营销页。
- 验证信息架构、视觉 token、组件和响应式，不接入真实支付、账号或 API Key。
- 需要滚动叙事时再调用 GSAP，且必须提供无动画降级。

详细边界见 `references/routing.md`。

## 验收

- 桌面 `1440x900`、宽屏 `1920x1080`、移动端 `390x844`。
- 无横向溢出、文字遮挡、错误裁切和无意义空白。
- 无动画状态完整可读。
- PDF 无空白页、断裂表格、错误页码和被裁切标题。
- 图片、字体、CDN 和离线状态有合理降级。
- 输出 `verification.md`，记录真实检查结果。
